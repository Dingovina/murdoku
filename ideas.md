# Список фич, которые хочется реализовать в дальнейшем (v2)


## UI
- Портреты собираются случайно из составных частей (лицо, волосы (форма + цвет), очки, борода, воротник) — в v1 портреты упрощённые (цвет + инициал)
- Рандомные имена людей и комнат (в v1 — заглушки «Подозреваемый_N»)
- Пусть для обвинения не нужно будет вводить имя подозреваемого. Вместо этого кнопка "Обвинить ... " будет автоматически подставлять имя порозреваемого, который оказался наедине с убитым (по расстановке пользователя), либо показывать ошибку и быть не доступной для нажатия, если этот инвариант не выполнен

## Backend
- Количество людей = размеру поля (N = size): по человеку в каждой строке и в каждом столбце — в духе судоку
- Сохранение всех игр в БД (SQLite), чтобы в дальнейшем сделать меню с выбором уровня
- Каждый из подозреваемых должен фигурировать как минимум в одной подсказке
- В каждой комнате должен быть как минимум 1 предмет
- Когда пользователь отправляет ответ, необходимо проверить его соответствие всем подсказкам и инвариантам игры. Если выяснится, что решение пользователя верное, но отличается от исходного решения - показать пользователю победу и сохранить seed + clues + user_solution + server_solution на сервере, чтобы можно было найти баг генерации/валидации и исправить его
- Хочется уметь считать коэффициент разнообразия набора подсказок, чтобы отсекать случаи с большим количеством однотипных подсказок (сейчас очень много подсказок осторонах света - временно выключил их)
- Хочется уметь считать коэффициент полезности подсказки (процент неподходящих под описание клеток), чтобы уметь контролировать количество подсказок того или иного типа в наборе (Но не понятно, как считать такой коэфициент для подсказок типа "В комнате_2 было не более 2 человек")

### Новые типы подсказок
- Объединение связанных подсказок в одно предложение, например подозреваемый_1 находился рядом с объектом_1 и объектом_2
- подозреваемый_1 находился рядом с женщиной (делим всех людей на мужчин и женщин - полезно в том числе для отрисовки портретов)
- подозреваемый_1 был в комнате не один 
- подозреваемый_1 ЕДИНСТВЕННЫЙ + существующая подсказка (если совместиво, например единственный находится на кровати)
